# User Stories

## US-1: User Registration

As a user I want to be able to register in Rush-POS so that I can have credentials to log in.

## US-2: User Login

As a user I want to be able to log in using my credentials so that I can access the main page.

## US-3: User Logout

As a user I want to be able to log out of my session so that only I can access the main page with my credentials.

## US-4: Admin User Management

As a User(Admin) I want to be able to register non admin users so that they can access the main page with non admin privileges.

## US-5: Item Creation

As a User(Admin) I want to be able to add items to the available items for sale in the POS system.

## US-6: Item Management

As an admin I want to update items or mark them as unavailable so outdated items can't be ordered.

## US-7: Table Management

As an admin I want to create and manage restaurant tables so orders can be assigned to them.

## US-8: Order Creation

As a user I want to create an order tied to a table and add items to it so I can send it to the kitchen.

## US-9: Order Updating

As a user I want to modify items in an order (change quantities, add notes, remove items).

## US-10: Order Checkout

As a user I want to close/complete an order so the table becomes available again.

## US-11: Main Dashboard

As a user I want to see a dashboard with tables and their status so I can quickly navigate the POS and manage orders.
